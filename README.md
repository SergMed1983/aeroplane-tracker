 у # ✈️ Трекер самолётов (Aeroplane Tracker)

Курсовая работа по модулю ООП. Программа для сбора, фильтрации и сохранения данных о самолётах, находящихся в воздушном пространстве выбранной страны, с использованием внешних API.

## 📌 Возможности программы
- Получение координат (bounding box) страны через API **nominatim.openstreetmap.org**.
- Получение списка самолётов в этом регионе через API **opensky-network.org**.
- Преобразование сырых данных в объекты класса `Aeroplane`.
- Валидация данных при создании объекта.
- Сохранение информации о самолётах в JSON-файл.
- Фильтрация по стране регистрации и диапазону высот.
- Вывод топа N самолётов по высоте полёта (сортировка по убыванию).

## 🏗️ Архитектура и ООП
Проект построен с соблюдением принципов SOLID:
- **Абстракции:** `AbstractAPI` и `AbstractSaver` наследуются от `ABC`, используют декораторы `@abstractmethod`.
- **Инкапсуляция:** Класс `Aeroplane` хранит данные и предоставляет методы для их сравнения (`__lt__`, `__gt__`, `is_higher_than`).
- **Обработка исключений:** Все запросы к API обёрнуты в `try...except` (перехват `RequestException`, `ValueError`).
